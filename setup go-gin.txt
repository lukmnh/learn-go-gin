setup gin :
create foldering first -> cmd/api for entry point
internal for application
migrations for database queries

after that, go mod init module-name
and then install dependencies for gin framework
go get -u GitHub.com/gin-gonic/gin, install driver sql
PostgreSQL -> go get-u GitHub.com/jackc/pgx/v5
pool connection on postgres ->  go get -u github.com/jackc/pgx/v5/pgxpool 


optional :
go get gorm.io/gorm
go get gorm.io/driver/postgres

jwt -> go get github.com/golang-jwt/jwt/v5

env -> go get github.com/joho/godotenv

hot reload (any saved file server auto reload) -> go install github.com/air-verse/air@latest
